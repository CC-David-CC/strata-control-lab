# The 39 experiments

The index walks from basic measurements through research instruments to applied
toy worlds. Every page includes exact inputs, its calculation, a limitations
panel and a downloadable example. Open the [local gallery](http://127.0.0.1:8876)
after following the [launch instructions](../README.md#start-the-lab).

The native applied bank contains 21 independent cases, not an adaptive agent
trajectory. The coding controller simulates actions; it does not execute shell
commands. Scene rendering draws typed shapes and never evaluates generated
JavaScript, SVG or Python. Text probes do not see the rendered image.

The finite action control and future-success pages calculate legal preferences
in Python and ask native GBNF to emit the selected code. They are not a native
full-vocabulary expert ensemble or a learned future discriminator. Changing a
lesson dial recomputes captured measurements; Live model reruns the disclosed
workload against a compatible server.

## Next research gates

Each page states a narrower next experiment. The broad gates are:

- Validate answer codes and score semantics for each new tokenizer/model.
- Compare semantic measurements with held-out labels and exact baselines.
- Keep state-dependent legality, model preference and application utility
  separate when extending a closed loop.
- Measure repeated wall time and numerical paths before claiming acceleration.
- Add native capabilities in a separate Strata contribution before depending on
  them here: per-token grammar replacement, arbitrary grammar-language mass,
  direct KV manipulation and full-vocabulary expert control remain proposals.

See [evidence and limits](EVIDENCE.md) and
[engine compatibility](ENGINE_COMPATIBILITY.md) before treating a demonstration
as an available native feature.
