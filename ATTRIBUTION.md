# Attribution and origin

The lab was developed in CC-David-CC's fork of
[Niko1221/Strata](https://github.com/Niko1221/Strata), then extracted as a separate
HTTP client. The inherited [MIT license](LICENSE) and its copyright notice are
preserved. The project name identifies the engine used for native measurements;
it does not imply upstream endorsement.

The extraction source is local commit
`8c99143e05234c02f2ccf41cc3361746b09773cd` on
`work/lab-applied-experiments` in `CC-David-CC/Strata-a5500`. That lab checkpoint
was not pushed before extraction, so it is deliberately not linked as a public
GitHub commit. All files necessary to use this lab are included here.

[The extraction manifest](docs/provenance/extraction.json) maps each copied file
to its original Git blob and SHA-256. These are hashes of the source bytes,
before package paths and documentation were adapted. Native recording bytes and
the portable example ZIP remain unchanged. The repository has fresh history;
Strata's engine and hardware files were not imported.

The locally served Outfit font retains its
[SIL Open Font License](control_lab/static/OFL.txt). There are no remote font or
analytics dependencies.
